# COMP3005Assignment3Q1
This repository is for my class at Carleton for the TA's to access and grade, nothing more

Running Instructions:
You must have Java downloaded on your computer to run this
There are 3 files in COMP3005Assignment3, src/main/java, target/classes, and pom.xml  

src/main/java   -   Main java file where the assignment code lives. The main.java file is what you want to use to run the application  
target/classes   -   ignore  
pom.xml   -   ignore  

to run, download COMP3005Assignment3 to your computer  
In the main.java file, there will be 5 variables to input. ip, port, database, user, and password  
you will need to create a postgreSQL database and populate the 5 variables with your own information  
once the data is populated and you have a database, you should run the 'addRequiredTable' function by typing it into the  'main' function and running on your IDE. This should create the required table and populate it  
do not run the addRequiredTable function more than once.  
Now you can test out the 4 functions I have created by typing them into the main function and populating any required   parameters based on the comments in the code (the 4 functions are below the 'main' function)
